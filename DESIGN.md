# Rishabh Bhagchandani portfolio

A personal data analytics, data science and AI/ML portfolio for recruiters and collaborators. A restrained, typographic site with blue accents; no imagery or animated backgrounds. Reference: dhruvi-05.github.io/my_portfolio/ for content structure, not personal claims.

## Tokens and ownership

`src/index.css` owns runtime tokens and maps them into Tailwind through `@theme inline`.

- Background #0d0f13; card #13171e; foreground #f2f4f8; secondary text #a5adbd; border #272e39.
- Accent #639bff. Accent buttons use dark foreground for contrast.
- Inter with system sans-serif fallback; monospace only for secondary category labels.
- Maximum content width 1160px, responsive 24px–40px outer gutters.
- Corners 12px, one-pixel borders; no heavy shadows or gradients.
- Main signature: a name-first hero with full-name typography, social links above, and a smaller data analyst / aspiring data scientist / AI/ML role line. Inspired by adi-1805.github.io/_Portfolio_/ name hierarchy, expertise columns and open spacing; retain the existing blue theme, all sections and no-photo direction.

## Behaviour

Data/ML projects precede application projects. Exact repository and demo links come from GitHub API/READMEs; Spice Garden remains unavailable until a link is provided. Sticky navigation with active section; accessible mobile menu and Escape dismissal. Anchor offsets account for the header. Radix/Shadcn tabs supply keyboard navigation, controlled React state filters mini projects. Unknown URLs are unavailable text with a visible Soon badge; never fake navigation. Scroll reveals progressively enhance visible HTML and respect reduced motion. Dates and unprovided performance metrics are not invented.
