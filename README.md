# Rishabh Bhagchandani | Portfolio

A modern, responsive personal portfolio built with React, TypeScript, and Vite. This site is designed to showcase my work, skills, experience, projects, and contact information in a polished, mobile-friendly format.

## Live Demo

Visit the portfolio: https://sweet-taffy-8a30d1.netlify.app/

## Overview

This portfolio was built to present:

- my professional profile
- my technical skills
- my projects and case studies
- my experience and achievements
- my resume and contact links

It is optimized for:

- fast loading
- mobile responsiveness
- accessibility
- easy customization
- clean deployment to static hosts

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix UI / Shadcn-style components
- HTML / CSS

## Features

- Responsive single-page portfolio
- Smooth scroll and reveal animations
- Project and mini-project sections
- Experience and skills highlights
- Contact section with direct links
- Resume download support
- Easy configuration via a central data file

## Getting Started

Requirements:

- Node.js 22.13 or newer

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Customization

Edit the portfolio data in:

```bash
src/data/portfolio.ts
```

Common values to update:

- GitHub profile
- LinkedIn profile
- email address
- resume URL
- project links
- mini-project categories and entries

Leave any URL empty to show a placeholder instead of a clickable link.

## Deployment

This project is static-site friendly and can be deployed to:

- Netlify
- Vercel
- GitHub Pages

For Netlify/Vercel:

- Build command: `npm run build`
- Publish directory: `dist`
